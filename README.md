# Nasty World

**Mature humor (18+): crude cartoon toilet and bug jokes. Not sexual, not for kids.**

A tiny arcade of free, short, gross browser games. Live: https://waytosea-oss.github.io/nasty-world/

| Game | Path |
|---|---|
| Bladder Brawl: hose the bugs back down the bowl | [`bladder-brawl/`](bladder-brawl/) |

- Static site, GitHub Pages, no build step. No ads, no accounts, no analytics.
- All art drawn in code (canvas), all sounds synthesized with WebAudio, fonts Lilita One, Fredoka and Titan One (SIL Open Font License).
- Logo options are in `shots/` (hub) and `bladder-brawl/shots/` (game).
- Adding a game: see [ADDING_GAMES.md](ADDING_GAMES.md). Difficulty notes: [bladder-brawl/BALANCE.md](bladder-brawl/BALANCE.md).
